装之前，
先把 18 项权限签了。

每个插件在 plugin.json 里写清楚自己要什么。每项都有中文说明和风险等级：中高风险在启用时弹一次；权限改过，即使同名同版本，也要重新确认。

  • ui添加自定义页面、标题栏入口、设置项与卡片（会改动界面）低
  • events订阅启动器事件（页面切换、游戏启动与退出、下载开始与结束）低
  • files在授权的目录里读写文件（插件自己的数据目录始终可用）低
  • net访问清单里授权的主机（发网络请求）低
  • net.dynamic在运行时申请访问新的主机（每次弹窗询问，可随时撤销）低
  • instance.read读取当前实例的信息：名称、加载器、版本号、模组数量（只读）低
  • logs.read读取游戏日志与崩溃报告（只读）低
  • mods.read查看当前实例的模组、资源包与光影列表（只读）低
  • skin修改离线皮肤（会改变你在游戏里看到的外观）中
  • instance.install往当前实例安装内容：mods、资源包、光影、数据包（会改动游戏文件）中
  • launch主动启动游戏（你没点「启动游戏」时也会把游戏跑起来）中
  • account读取当前账号信息：用户名、UUID、登录方式（只读，拿不到令牌）中
  • settings.global读取启动器全局设置：路径、语言等偏好（只读）中
  • instance.select切换当前选中的实例（会改变之后「启动游戏」用的版本）中
  • mods.write启用或禁用实例里的模组、资源包与光影（会改动游戏文件）中
  • args修改游戏启动参数（JVM 参数与游戏参数，能注入 -javaagent）中
  • plugins查看、安装、启用、禁用或卸载其他插件（市场类插件需要）中
  • process启动外部进程（等同于在你的电脑上执行代码）高

风险分级是提示，不是沙箱。真要装了带 process 权限的 DLL，它就能在你的电脑上跑任何东西。别装来路不明的插件。

三样东西，
就能写一个插件。

不用改启动器源码，不用等合并。一个清单、一个 DLL、一个目录，VB 和 C# 都能写。联机页、下载页、AI 助手的卡片，都是这套接口写出来的。

  1. 1

    一份 plugin.json

    id、名称、版本、作者、入口类、DLL、要的权限。写清楚，启动器才认。

  2. 2

    一个 DLL

    实现 IPclPlugin，两个方法：OnLoad 和 OnUnload。想画界面再加 IPclPluginUi。

  3. 3

    放进插件目录

    PCLHarness\Plugins\<id>\。回到插件页点「重新扫描」，它就出现在列表里了。

plugin.json

{
  "id": "hello",
  "name": "你好插件",
  "version": "1.0.0",
  "author": "你",
  "entry": "HelloPlugin",
  "dll": "Hello.Plugin.dll",
  "permissions": [ "ui" ]
}

HelloPlugin.vb

Public Class HelloPlugin
    Implements PCL.IPclPlugin

    Public Sub OnLoad(Host As PCL.PluginHost) _
            Implements PCL.IPclPlugin.OnLoad
        Host.Log("你好，插件跑起来了")
    End Sub

    Public Sub OnUnload() Implements PCL.IPclPlugin.OnUnload
    End Sub
End Class

先说难听的

这是官方 PCL 吗？
不是。PCL Harness 是基于龙腾猫跃的 PCL2 开源版做的独立二次开发，不隶属 PCL 官方，也不代表官方立场。关于页第一位写的是原作者。
会被 SmartScreen 拦吗？
会。没有代码签名，第一次运行会提示「Windows 已保护你的电脑」。点「更多信息」，再点「仍要运行」；或者先跑一次 Unblock-File。介意的话，源码是公开的。
我的游戏和存档会被动吗？
不会。迁移只复制 PCL 的设置、插件和启动器数据，游戏目录不碰；原版 PCL 的文件也不动。两个启动器可以同时开着。
插件会不会乱来？
权限是闸门，不是沙箱。18 项按低、中、高分级，高风险在启用时拦你一次，权限改了再拦一次。但真装了带 process 权限的 DLL，它就能在你的电脑上执行代码。别装来路不明的插件。
联机为什么连不上？
多半是对称 NAT 或 CGNAT，TUN 不改变打洞能力。联机还需要管理员权限和 wintun。连不上时，可以把诊断导出来看是哪一步断的。
卸载会删什么？
插件卸载会进 Windows 回收站，能捞回来。启动器的配置在 PCLHarness\ 里，自己删。游戏和存档不碰。
支持哪些系统？
Windows 10 / 11 x64，需要 .NET Framework 4.8（Win10 1903 起自带）。
正版登录为什么提示没配置？
开源版不带微软登录的 ClientID，要自己申请一个填进去。离线登录不受影响。
