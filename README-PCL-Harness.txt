PCL Harness（自编版）3.0.0
====================

这是基于 PCL2 v2.13.1.1 官方开源代码自行编译、修改的版本，非官方发布。
许可：见 LICENCE（《PCL 分发有限许可》）。本目录只是个人研究与自用产物。

一、这个版本改了什么
--------------------
1) 改名：窗口标题 PCL Harness　自编版；程序集标题/产品名 PCL Harness；
   可执行文件更名为 PCL Harness.exe；左上角 logo 后带「Harness」后缀；版本号 3.0.0。
2) 顶部「插件」入口 + 插件框架（本版核心）：
   - 插件目录：本目录\PCL\Plugins\<插件文件夹>\plugin.json
   - 支持声明型插件（只放 json）与可执行插件（DLL 实现 PCL.IPclPlugin）
   - 插件页可启用/禁用/重新扫描/打开目录；启用状态存 PCL\Plugins\plugins.json
   - 宿主 API：写日志、左下角提示、弹窗、打开网址、数据目录
   - **v2 扩展点**（再实现 PCL.IPclPluginUi 即可）：
       · 自定义页面：返回任意 UserControl，宿主包成正式页面（切换动画/滚动一致）
       · 标题栏入口：在「插件」右侧注入按钮，点开插件页面或只执行一段代码
       · 设置项：布尔/文本两类，值自动存 PCL\Plugins\plugins.settings.json
   - 插件页下方会列出所有注册的页面与设置项，可直接打开页面、改设置
   - 插件开发文档：PLUGIN-DEV.md；示例源码：samples\DemoPlugin（含 build.ps1）
3) 暗色「蓝黑」主题：文字/卡片/输入框/弹窗全部重配，正文对比度 > 10:1；
   并修正了暗色下悬浮反馈与弹窗阴影过亮的问题。
4) 更新检查不再检查官方源（官方源已停止更新）：不设 PCL_UPDATE_JSON_URL 时完全离线，
   点「检查更新」只提示未配置；设了才去取自建 JSON，示例见 update.example.json。

二、怎么用
----------
直接运行 PCL Harness.exe。首次启动会有「开源版本说明」弹窗（上游行为），确定即可。
插件：把插件文件夹放进 PCL\Plugins\ 下，进「插件」页启用。
自定义页面插件：启用后标题栏右侧会出现它注册的入口按钮。
更新源：set PCL_UPDATE_JSON_URL=https://你的站点/pcl-update.json

三、已知限制
------------
- 上游开源版本身不含：CurseForge API、微软正版登录、联网通知、主题切换、百宝箱（弹窗里已列出）。
- 插件扩展点目前只有「页面 / 标题栏入口 / 设置项」，尚无事件挂钩（如启动流程、下载回调）。
- 插件页面没有内置 Loader；需要后台数据时请在插件里自行起线程 + RunInUi。
- 本版未做代码签名；Windows 可能提示来源未知。
- 界面主色相仍为蓝色（西 220°），符合 LICENCE 第 5 条要求。
