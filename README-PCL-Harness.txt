PCL Harness（自编版）3.9.2
====================

这是基于 PCL2 v2.14.0.0 官方开源代码自行编译、修改的版本，非官方发布。
许可：见 LICENCE（《PCL 分发有限许可》）。本目录只是个人研究与自用产物。

一、这个版本改了什么
--------------------
1) 改名：窗口标题 PCL Harness　自编版；程序集标题/产品名 PCL Harness；
   可执行文件为 PCL Harness.exe；左上角 logo 后带「Harness」后缀；版本号 3.9.2。
2) 独立配置目录：数据统一放在本目录的 PCLHarness\ 下，与原版 PCL 互不覆盖；
   用户数据在 %AppData%\Roaming\PCLHarness\；首次启动可一键迁移旧设置与插件。
3) 插件框架（当前 API v8，本版核心）：
   - 插件目录：PCLHarness\Plugins\<插件文件夹>\plugin.json
   - 支持声明型插件（只放 json）与可执行插件（DLL 实现 PCL.IPclPlugin）
   - 插件页可启用/禁用/重新扫描/打开目录/重新加载/回滚到上一版/重新确认权限
   - 扩展点：自定义页面、标题栏入口、设置项、实例右键菜单、实例与内容读写
   - 权限分级 0/1/2（普通/中风险/高风险），启用前逐条确认；权限清单变化会再次询问
   - 崩溃熔断、热重载、单份备份与回滚；卸载插件会清除权限记录、目录移入回收站
   - 插件市场：插件页可一键打开 https://github.com/Badqf/PCL-Harness-Market
   - 开发文档：PLUGIN-DEV.md；SDK 与示例见 Release 附件的 PCL-Harness-Plugin-SDK-*.zip
4) 下载与联机改为由插件提供（3.9.0 起）：
   - 本体不再内置「下载」「联机」页面，装上市场里的「下载页面」「联机页面」即可恢复
   - 已经下载到本地的游戏、Mod、整合包、资源包与联机配置全部保留，不会被删除
   - 也可手动下载 .pclplugin 后，在插件页用「导入插件…」安装
5) 主题：深色 / 浅色外观，主色调限定蓝色系（LSC 合规要求），另有 4 个预设一键切换。
6) 更新：通过 GitHub Releases 自检更新（ghfast 镜像优先、官方源兜底），
   默认静默下载、退出时替换；也可在设置里手动检查。

二、怎么用
----------
直接运行 PCL Harness.exe。首次启动可迁移旧 PCL 数据，随后可选查看「介绍页」。
下载/联机：进「插件」页 →「下载插件市场」，在插件市场安装「下载页面」「联机页面」。
插件：也可把插件文件夹放进 PCLHarness\Plugins\ 后点「重新扫描」。
介绍页：可在「设置 → 启动」里关闭或重新打开。

三、已知限制
------------
- 插件接口随版本演进，插件需声明 minApiVersion；低于宿主要求时会拒绝加载并提示。
- 本版未做代码签名；Windows 可能提示来源未知（详见 README.md 的说明）。
- 界面主色相仍为蓝色（约 220°），符合 LICENCE 第 5 条要求。
- 下载/联机页面来自插件，问题排查请连带插件版本一起反馈。
